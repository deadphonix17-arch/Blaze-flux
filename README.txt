Overgeared Steel & Diamond Smelting (addon)

1. Make a new GitHub repo and upload everything in this folder (including the hidden .github folder).
2. The "build" action runs automatically; download the jar from the run's Artifacts (use the one WITHOUT "-sources").
3. Put that jar in your mods folder next to Overgeared. Needs Fabric API.

Also use the patched smeltable_ore_blocks jar so its diamond recipes don't conflict.
